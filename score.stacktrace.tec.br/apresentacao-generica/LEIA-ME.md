# Screenshots de apresentação — Score Rede Demonstrativa

Abra index.html para visualizar a galeria. As sete capturas em PNG estão em screenshots/.

- Computador: 3200 × 2240 pixels.
- Celular: 1290 × 3000 pixels.
- Os templates, estilos e comportamentos são os do sistema atual.
- Unidades, endereços, notas e observações são fictícios.
- O exemplo completo usa 36 respostas e score 94,75/100, calculado pelo sistema.
- Nenhuma conexão com o banco nem gravação de auditoria foi realizada.

Para gerar novamente a partir da raiz do projeto (Chrome instalado):

```powershell
npm.cmd install --prefix storage/presentation-tools --no-save --package-lock=false playwright-core
node scripts/create-anonymous-presentation.mjs
```
